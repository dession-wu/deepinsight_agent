/ 01 · THE PIPELINE

一次请求，
四层研究。

每一个结论都经过采集、对照和编排。你看到的不只是答案，还有答案如何形成。

01COLLECT

实时采集

抓取行情、公告、新闻与财报，建立当前市场上下文。

02READ

分工研究

多个专职 Agent 并行阅读各自领域，减少单一视角遗漏。

03CHECK

交叉验证

对比不同来源与观点，把事实、推断和风险分开呈现。

04REPORT

结构化输出

异步生成可阅读、可追踪、可继续调用的投资情报报告。

/ 02 · CAPABILITIES

研究有边界，
结论才可信。

把模型能力放在清晰的流程里，让数据来源、任务状态与结果边界都可被理解。

01AGENTS

多智能体协作

行情、资讯和报告角色各司其职，面向复杂问题并行工作。

02FETCHERS

实时联网获取

围绕当下市场收集信息，不把过期知识伪装成实时判断。

03REASONING

来源与推理链

输出结构化摘要，并保留进一步查看完整结果的 API 路径。

04ASYNC

异步任务架构

长任务立即返回 task_id，后台执行不阻塞前端请求。

05BOUNDARY

明确分析边界

情报用于辅助研究，不把模型输出包装成确定性的投资承诺。

06API FIRST

API 优先接入

网页演示与 API 使用同一套任务流程，便于集成到自己的工具。
